## 🎯 Описание

FreeTalk — это мощный инструмент для синтеза речи на русском языке, разработанный в соответствии с техническим заданием. Программа использует современные нейросетевые алгоритмы библиотеки Silero TTS для достижения максимально естественного звучания и полностью работает без интернета после первой загрузки модели.

### Ключевые особенности

* 🚀 **Высокое качество** синтеза благодаря нейросетевым алгоритмам
* 💻 **Полная автономность** — работает без интернета
* 🎨 **Интуитивный интерфейс** с поддержкой форматирования текста
* 🔧 **Гибкие настройки** скорости, пауз и голосовых профилей
* 💾 **Сохранение** синтезированной речи в аудиофайлы (WAV)
* ⌨️ **Горячие клавиши** для всех основных действий

## ✨ Основные возможности

### 🎙️ Синтез речи

* Конвертация текста в речь с естественным звучанием
* Поддержка русского языка
* Стриминговый синтез — воспроизведение начинается до окончания синтеза всего текста
* 6 голосов на выбор:

  * **aidar** — мужской, чёткий
  * **baya** — женский, мягкий
  * **kseniya** — женский, выразительный
  * **xenia** — женский, эмоциональный
  * **eugene** — мужской, спокойный
  * **random** — случайный выбор

### 📝 Редактор текста

* Панель форматирования: шрифты (Arial, Times New Roman, Georgia, Courier New, Calibri и системные), размер, цвет (пресеты + диалог выбора)
* Жирный / курсив / подчёркнутый
* Настройки форматирования сохраняются между сеансами
* Поддержка специальных символов

### 🔤 T9 предсказание

* Автоматическое предсказание слов (5 блоков с предсказаниями)
* **Динамическое обучение**: новые слова из редактора автоматически добавляются в словарь и получают повышенный приоритет — отдельная кнопка «Обучить» не требуется
* Корректная работа со знаками препинания (вставка `.` `,` `!` `?` больше не удаляет набранное слово)
* Кнопка вызова T9 скрыта из интерфейса по умолчанию (включается в настройках: `t9_show_button`)
* Работа без интернета

### ⌨️ Горячие клавиши

| Сочетание | Действие |
|---|---|
| `Ctrl+Enter` | Озвучить текст |
| `Ctrl+S` | Сохранить аудио (WAV) |
| `Esc` | Остановить воспроизведение |
| `Ctrl+Del` | Очистить текст |
| `Alt+R` | Фокус в редактор текста |
| `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | Масштаб + / − / сброс |
| `Ctrl+Z` / `Ctrl+Y` | Отмена / повтор |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | Жирный / курсив / подчёркнутый |
| `Ctrl+Q` | Выход |

### 🎚️ Настройки синтеза

* Регулировка скорости произношения (50–200%)
* Настройка длительности пауз (1–2 секунды)
* Корректировка произношения и ударений
* Частотный эквалайзер

### 💾 Сохранение

* Сохранение синтезированной речи в WAV формат
* Диалог выбора файла (`QFileDialog`); путь по умолчанию: `~/Downloads/FreeTalk/FreeTalk_YYYYMMDD_HHMMSS.wav`
* Возможность сохранения с любым именем в любую папку

### 🔍 Интерфейс

* Масштабирование интерфейса (50–400%), значение сохраняется между запусками
* Сохранение настроек между сеансами
* Современный дизайн, поддержка High-DPI

## 📦 Установка

### Вариант 1: Установщик (рекомендуется)

1. Скачайте `FreeTalk_Setup_v<версия>.exe` со страницы [Releases](https://github.com/nmak1/speech_synthesizer/releases)
2. Запустите установщик и следуйте инструкциям мастера
3. После установки запустите программу через ярлык на рабочем столе

### Вариант 2: Портативная версия

1. Скачайте `FreeTalk.exe` со страницы [Releases](https://github.com/nmak1/speech_synthesizer/releases)
2. Запустите файл напрямую
3. При первом запуске программа скачает необходимые модели (≈150 МБ)

### Вариант 3: Из исходного кода
