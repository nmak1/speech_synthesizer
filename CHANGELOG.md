# Changelog

Все значимые изменения проекта документируются в этом файле.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [2.1.0] - 2026-10-19

### ✨ Новое
- **Панель форматирования текста** (`src/gui/format_bar.py`): выбор шрифта
  (Arial, Times New Roman, Georgia, Courier New, Calibri и системные),
  размера, цвета (8 пресетов + диалог выбора), жирный/курсив. Настройки
  применяются к выделению или всему тексту, сохраняются в QSettings.
- **Динамическое обучение словаря T9**: новые слова из редактора
  автоматически добавляются в словарь с приоритетом; отдельная кнопка
  «Обучить» больше не нужна.
- **Горячие клавиши**: `Ctrl+Enter` — озвучить, `Ctrl+S` — скачать WAV,
  `Ctrl+Z/Y` — отмена/повтор, `Ctrl+B/I/U` — стиль, `Ctrl+=/-/0` — масштаб,
  `Esc` — остановить воспроизведение.
- **CI GitHub Actions** (`.github/workflows/ci.yml`): pytest на ubuntu-latest
  (offscreen Qt) при каждом push/PR + smoke-проверка на windows-latest для main.

### 🐛 Исправлено
- **Кнопка T9**: вставка знаков препинания больше не удаляла набранное слово
  (логика word-boundary); кнопка скрыта из интерфейса по умолчанию
  (`t9_show_button=False`, включается в настройках).
- **Сортировка предсказаний T9** в `predict()` — частотный порядок восстановлен.
- **Безопасность потоков**: все фоновые операции (загрузка модели, синтез,
  сохранение) переведены с `threading.Thread` на `QThread`-воркеры
  (`src/workers.py`); взаимодействие с UI только через сигналы — устранены
  гонки и случайные падения в Windows.

### 🔧 Улучшения
- **Единый источник путей** (`src/paths.py`): ресурсы корректно находятся и в
  исходниках, и в PyInstaller-сборке; относительные пути заменены везде.
- **Единый источник версии** (`src/version.py` = 2.1.0): config, main, release
  и CI берут версию оттуда.
- `FreeTalk.spec`: в `hiddenimports` добавлены `src.paths`, `src.version`,
  `src.workers`.

### 🧪 Тесты
- Внедрён **pytest-qt**: `tests/conftest.py` (фикстуры `tmp_config`,
  `isolated_settings`), `tests/test_t9_predictor.py` (13 тестов логики T9),
  `tests/test_gui_widgets.py` (20 GUI-тестов: TextEditor, FormatBar,
  T9Widget, хоткеи MainWindow; torch/аудио мокаются). Итого 33 теста,
  запуск: `pip install -r requirements-dev.txt && pytest`.
- `pytest.ini` с `qt_api=pyqt5`; `requirements-dev.txt` (pytest==8.3.3,
  pytest-qt==4.4.0).

### 📦 Зависимости
- Версии в `requirements.txt` приведены к фактически используемым:
  PyQt5 5.15.9→5.15.11, torch/torchaudio 2.5.0→2.7.1; `pywin32` помечен
  как Windows-only (`sys_platform == "win32"`).

## [2.0.0] - 2026-09-23

### 🚀 Производительность
- **Устранена задержка запуска синтеза** — с 9 сек до 0.7 сек (в 13 раз быстрее)
- **Повторный синтез из кэша** — 1 мс вместо 1.5 сек
- **Двухпроходный warm-up модели** — первый реальный синтез теперь ~700 мс
- **Streaming-синтез по предложениям** — звук начинается до окончания синтеза всего текста

### 🐛 Исправлено
- Падение приложения с кодом `0xC0000409` при старте
- Зависание при клике во время загрузки модели (race condition warm-up)
- Задержка воспроизведения 1.5 сек (теперь ~0 мс)
- Кнопка «Скачать» не работала, если синтез уже выполнялся
- «Зависший» `_synthesis_lock` после синтеза
- Логотип отображался как точка (High-DPI scaling)
- Спам «Конфигурация сохранена» при движении ползунка зума
- `AttributeError: 'MainWindow' object has no attribute 'text_editor'`

### 🎨 Интерфейс (Пункт 4 ТЗ)
- Кнопки «Озвучить»/«Скачать» увеличены в 1.5 раза (64px высота, шрифт 20pt)
- Метки «Голос:»/«Скорость:» увеличены (18pt bold)
- Кнопки масштабирования `+`/`−` увеличены в 2 раза (60×60)
- Ползунок масштаба увеличен (320×48, handle 32px)
- Метка значения масштаба крупнее (80×60, 14pt bold)
- Перераспределено свободное пространство на экране
- Логотип отображается в правильных пропорциях (260×146)

### 🔤 T9 (Пункт 4 ТЗ)
- Кнопка T9 увеличена до 70×50, шрифт 18pt bold
- Кнопки пунктуации увеличены до 55×50, шрифт 18pt bold
- Поля предсказаний увеличены до 160×50, шрифт 16pt bold
- Пустые поля предсказаний **скрываются**, когда нет предсказаний

### 💾 Сохранение
- Диалог выбора файла через `QFileDialog.getSaveFileName`
- Возможность изменить папку и имя файла перед сохранением
- Путь по умолчанию: `~/Downloads/FreeTalk/FreeTalk_YYYYMMDD_HHMMSS.wav`

### 🛠️ Техническое
- `SileroTTS` — двухпроходный warm-up, `_apply_lock` для потокобезопасности
- `AudioPlayer` — переиспользуемый `OutputStream`, `prewarm()`, замеры `prep/write`
- `MainWindow` — сигналы вместо `QTimer.singleShot` из фоновых потоков
- `_download_ready_signal` для передачи numpy-массива в UI-поток
- Защита от ранних вызовов `on_text_changed` (hasattr-проверки)
- Убрано дублирование в `_split_sentences`

### 📦 Сборка
- `release.py` — обновлён под v2.0, больше не удаляет `FreeTalk.spec`
- `requirements.txt` — актуализирован (убраны неиспользуемые `pydub`, `python-dotenv`)
- `setup.iss` — версия 2.0.0, обновлены пути
